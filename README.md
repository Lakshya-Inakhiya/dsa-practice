# dsa-practice

My data structures and algorithms practice, written from scratch in Python, plus C++ fundamentals.

| Folder | What's inside |
|--------|---------------|
| `sorting/` | Bubble, selection, insertion, merge, quick and heap sort |
| `arrays/` | Largest / second largest, sorted check, remove duplicates |
| `hashing/` | Brute-force vs hash-map frequency counting |
| `problems/` | Matrix spiral, layer rotation, sparse matrix, Pascal's triangle, Tower of Hanoi, permutations, bracket balancing, isomorphic strings |
| `mini-projects/` | ATM simulation, dice rolling game |
| `cpp-basics/` | Variables, loops, conditionals, strings, typedefs, namespaces |
| `notes.py` | Sorting, searching and linked lists, easy to hard |

## Run

```bash
python3 sorting/MergeSort.py
g++ cpp-basics/HelloWorld.cpp -o hello && ./hello
```
